# [WSB_MVP] Balloon Out

---

## 1. 타이틀 및 소개

**프로젝트명:** Balloon Out (가칭: WSB_BalloonOut)

**한 줄 소개:** 화살표를 터치하여 Snake처럼 이동시키고, 그리드 밖으로 탈출시켜 동일 색상 풍선을 터뜨리는 하이퍼캐주얼 퍼즐 게임

**장르:** 하이퍼캐주얼 퍼즐 (ArrowEscape + Target Pop 하이브리드)

## 3. 구현 상세

### 장르적 특징 분석

**기반 장르:** Arrow Escape (화살표 탈출 퍼즐)
- 화살표를 그리드에서 빼내는 퍼즐
- 순서 의존성으로 난이도 조절
- 직관적인 조작 (탭 한 번)

**차별화 요소:** Target Pop (풍선 터뜨리기)
- 탈출만으로 끝나지 않고 풍선 매칭
- Queue 시스템으로 순서 강제
- 색상 매칭으로 추가 인지 요소

**하이브리드 장점:**
- Arrow Escape의 공간 퍼즐 + Target Pop의 매칭 만족감
- 두 가지 성공 요소 (탈출 + 팝)로 보상감 증대

### 3-1. 게임의 기본 룰

**기본 룰:**

1. **터치 입력**: 화살표를 탭하면 화살표가 Head 방향으로 이동 시작
2. **Snake 이동**: 머리가 한 칸 이동 → 몸통이 따라옴 → 꼬리 위치가 비워짐
3. **충돌 판정**: 이동 중 다른 화살표 Body와 겹치면 충돌
4. **충돌 시 복귀**: 이동했던 경로를 역순으로 되돌아감 (바운스백)
5. **탈출 판정**: Head가 그리드 경계 밖으로 나가면 탈출 시작
6. **탈출 완료**: 모든 셀이 순차적으로 그리드 밖으로 나감
7. **호밍 이동**: 탈출한 화살표가 화면 상단 풍선 영역으로 날아감
8. **풍선 팝**: 동일 색상 풍선과 매칭되면 풍선 팝
9. **Queue 업데이트**: Lane의 다음 풍선이 활성화됨
10. **승리 조건**: 모든 풍선이 팝되면 클리어
11. **패배 조건**: 이동 가능한 화살표가 없는데 풍선이 남아있음 (데드락)

**인게임 핵심 기믹 로직:**

```
충돌 판정 (한 칸씩 체크):
  newHead = head + direction
  if newHead가 그리드 밖: return ESCAPE
  if newHead가 다른 화살표 셀과 겹침: return BLOCKED
  else: return MOVE_OK
```

**아웃게임 핵심 요소 (MVP):**
- **레벨 시스템**: JSON 기반 레벨 데이터 로드
- **스타 시스템**: 이동 횟수 또는 시간 기준 1~3스타
- **진행 저장**: PlayerPrefs로 클리어 현황 저장

**IAA 핵심:**
- **인터스티셜**: 3~5판마다 레벨 시작 시
- **보상 광고**: 클리어 후 보너스 스타, 실패 시 컨티뉴

**IAP 핵심:**
- **광고 제거**: 인터스티셜 영구 제거
- **힌트 팩**: 풀이 순서 표시 기능

### 3-3. 게임의 세부 메커니즘 명세

**1. Snake 이동 메커니즘**

```
입력: 화살표 터치
상태: idle → moving → (escaped | bounced)

한 스텝 이동:
  1. newHead = head + DIR_VECTORS[direction]
  2. if !isInBounds(newHead):
       state = escaping
       return
  3. if isOccupied(newHead):
       state = blocked
       return
  4. cells.unshift(newHead)  // 머리 추가
  5. cells.pop()              // 꼬리 제거
  6. animate()
  7. repeat
```

**2. 충돌 판정 로직**

```
function isBlocked(block):
  occupied = getAllOccupiedCells(except: block.id)
  head = block.cells[0]
  nextPos = head + DIR_VECTORS[block.direction]
  return occupied.contains(nextPos)
```

**3. 탈출 시퀀스**

```
function escapeSequence(block):
  while block.cells.length > 0:
    for each cell in block.cells:
      cell.position += direction
    animate(duration: 60ms)
    removeTailCell()
    await(60ms)
  spawnHomingArrow(block.color, exitPosition)
```

**4. 호밍 화살표**

```
function homingArrow(color, startPos):
  targetBalloon = findTargetBalloon(color)
  if !targetBalloon: flyAway()
  else:
    bezierPath = calculateBezier(startPos, targetBalloon.position)
    animate along bezierPath
    onComplete: popBalloon(targetBalloon)
```

**5. 풍선 팝 매칭**

```
function popBalloon(color):
  for each lane in queues:
    if lane.lastBalloon.color == color:
      lane.pop()
      playPopEffect()
      return HIT
  return MISS
```

## 5. 아이디어 체크

### 5-1. 흥행 체크

**1. 핵심 기믹이 흥미를 유도하는가?**
- YES: Snake 이동 + 충돌 바운스로 예측 가능성과 긴장감 동시 제공
- 탈출 후 호밍 + 풍선 팝으로 이중 만족감

**2. 성과가 있는 대상의 카피캣 전략인가?**
- YES: Arrow Escape (검증된 장르) + Bubble Shooter (팝 만족감) 조합
- 차별화 요소로 단순 카피 회피

**3. 유저가 좋아할 만한 요소:**
- 직관적 조작 (탭 한 번)
- 시각적 만족감 (팝, 파티클)
- 퍼즐 해결 성취감
- 짧은 세션 (1-2분)

**4. 흥행 요소 근거:**
- Arrow Escape 장르 검증됨 (다수 히트작)
- 풍선 테마는 보편적 호감
- 하이퍼캐주얼 시장 규모 유지

### 5-2. 핵심 인게임 화면 체크

**1. 어떤 게임인지 설명:**
- 화살표가 가득 찬 그리드에서 화살표를 탭하면 Snake처럼 이동
- 다른 화살표에 막히면 바운스백, 비어있으면 탈출
- 탈출한 화살표가 상단 풍선으로 날아가 동일 색상 풍선 터뜨림
- 모든 풍선을 터뜨리면 클리어

**2. 인게임 요소 논리적 기술:**
- 상단: Queue 영역 (Lane별 풍선 배열, 마지막이 활성)
- 하단: 그리드 영역 (화살표 배치, 점유/비점유 셀)
- 화살표: Head(방향 표시) + Body(꺾이는 경로)
- 터치 피드백: 이동 애니메이션, 충돌 바운스, 팝 이펙트

**3. 화면 구성 이미지화:**
- 위 3-5 섹션 참조

**4. 핵심 기믹이 재미있는 이유:**
- **예측과 실행**: 어떤 화살표를 먼저 빼야 할지 계획 → 실행 → 성공/실패 피드백
- **연쇄 해결**: 막혀있던 화살표가 뚫리면서 연쇄 탈출 가능
- **시각적 보상**: 탈출 → 호밍 → 팝의 일련의 시각 흐름

### 5-3. 핵심 KPI 산출 및 체크

**1. ROAS 목표 달성 영향 요소:**

| 요소 | 영향도 | 현재 예측 |
|------|--------|-----------|
| CPI | 높음 | $0.30-0.35 |
| D1 Retention | 높음 | 35% |
| D7 Retention | 중간 | 12% |
| ARPDAU | 높음 | $0.04-0.06 |
| 평균 유지일수 | 높음 | 8-10일 |

**2. 보수적 ROAS 계산:**
```
LTV = ARPDAU × 평균 유지일수
LTV = $0.04 × 8 = $0.32

ROAS 28일 = LTV / CPI
ROAS 28일 = $0.32 / $0.35 = 91.4%

보수적 조정 (0.5x):
Adjusted ROAS = 91.4% × 0.5 = 45.7%

→ 28일 ROAS 40% 목표 달성 가능 (보수적으로도)
```

**3. 플레이타임 30분 목표:**
- 세션당 평균 5분 × 일 6세션 = 30분
- 레벨당 1-2분, 광고 시청 시간 포함
- 적정 난이도로 실패/재시도 유도

### 5-4. 1만명 유저 마케팅 집행 예측

**가정: CPI $0.35, 마케팅 예산 $3,500**

| KPI | 목표치 | 달성 가능성 | 조치 |
|-----|--------|-------------|------|
| D1 Retention | 35% | 70% | 튜토리얼 개선, 초반 난이도 완화 |
| D7 Retention | 12% | 60% | 일일 보상, 레벨 다양성 확보 |
| ARPDAU | $0.04 | 80% | 광고 빈도 최적화, 보상 광고 유도 |
| 세션수/일 | 4 | 75% | 푸시 알림, 일일 챌린지 |
| 플레이타임 | 20분 | 65% | 레벨 밸런스, 컨티뉴 기능 |

**달성 가능성 기반 ROAS 추정:**

```
가중 LTV = ARPDAU × 평균 유지일수 × 달성률
        = $0.04 × 8 × 0.8 × 0.7 × 0.65
        = $0.116

ROAS = LTV / CPI
     = $0.116 / $0.35
     = 33.1%

조치 적용 시:
D1 Retention 40% 달성 (튜토리얼 개선)
ARPDAU $0.05 달성 (광고 최적화)

조정 LTV = $0.05 × 10 × 0.85 × 0.75 × 0.70
        = $0.223

조정 ROAS = $0.223 / $0.35 = 63.7%

→ 조치 적용 시 ROAS 40% 초과 달성 가능
```

**최종 계산 근거:**
1. CPI $0.35: 유사 장르 평균 기반
2. D1 35%: 하이퍼캐주얼 퍼즐 평균

4. 평균 유지일수 8-10일: D1-D7 retention 기반 추정
5. ROAS 40%: 보수적 추정에서도 달성 가능, 최적화 시 60%+ 가능
